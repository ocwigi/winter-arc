# Winter Arc

A phone-friendly winter habit tracker for June, July, and August 2026.

Open `index.html` to run the app.

## Current MVP

- Daily habit tracking
- 92-day winter scorecard
- Weekly targets for gym, sauna, steps, and AI learning
- Weight and body-fat progress goals
- Body trend chart
- Winter quest visuals
- Browser-based local saving

## Data note

The app stores entries in the browser on the device you use. App updates can be published through GitHub Pages, but cross-device data sync would require a backend/database in a later version.
